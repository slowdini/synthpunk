# Synthpunk — Zed Theme Extension

High-energy synthwave-inspired color themes for Zed.

## Theme Families

### Synthpunk Pastel

- **Synthpunk Pastel Dark** — Deep purple synthwave aesthetic
- **Synthpunk Pastel Light** — Warm peachy/pink light variant

### Synthpunk Neon

- **Synthpunk Neon Dark** — Electric vaporwave neon on deep purple-black
- **Synthpunk Neon Light** — Experimental holographic iridescence

## Install

Synthpunk is not yet in the Zed extension registry (a listing is coming soon). Until then, install it as a dev extension:

1. Clone this repository
2. Open Zed
3. Go to **Extensions** (or run `zed: extensions`)
4. Click **Install Dev Extension** (or run `zed: install dev extension`)
5. Select the `themes/zed/` directory
6. Select your preferred theme variant from the theme picker
